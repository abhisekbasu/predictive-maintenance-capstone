# Predictive Maintenance — Engine Failure Detection

## Project Overview
Machine learning system to predict engine failures from sensor data.
Built as part of PGP in Machine Learning and AI — Capstone Project.

## Best Model
- Algorithm : Random Forest Classifier
- Recall    : 0.8116
- ROC-AUC   : 0.6750
- Training  : 15,628 records, 11 features

## Repository Structure
- deployment/        : Streamlit app, Dockerfile, requirements.txt
- data/              : Placeholder — data hosted on Hugging Face
- .github/workflows/ : GitHub Actions automation pipeline
